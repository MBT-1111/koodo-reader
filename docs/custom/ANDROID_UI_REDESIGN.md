# Android UI 重构与进度

2026-11-02。用户指定手机上已安装的官方 Koodo Reader 作为参考。已实际查看其首页、书架、笔记、设置、阅读工具栏、目录、排版和主题面板。手机主界面、阅读交互、分组设置及全局笔记按下述三个批次实施。

## 开始时机

建议现在开始。当前已经完成本地导入、书库、阅读、进度保存、目录、书签、笔记、高亮和字体的基础闭环，并有浏览器及真机回归。手机主导航和阅读操作结构可以在此基础上确定，后续背景资源、锁屏、后台朗读等能力按新结构接入。

继续使用现有 React、Zustand、Capacitor 和阅读引擎。主要调整 Android 的页面组织及交互组件，复用已有数据、存储和阅读接口。桌面界面继续沿用当前布局。

## 官方界面的参考结论

| 区域 | 实际观察 | 本项目建议 |
| --- | --- | --- |
| 主导航 | 底部首页、书架、笔记、设置四个入口 | 将手机的主要去向常驻底部，减少打开抽屉再寻找功能的步骤 |
| 首页 | 继续阅读横向卡片、常用分类、封面网格 | 突出恢复阅读；保留导入、搜索、收藏和最近阅读等已有能力 |
| 书架 | 独立入口、明确的空状态和创建操作 | 复用现有书架/分类逻辑，使用手机页面布局 |
| 笔记 | 笔记和高亮切换，附筛选入口 | 复用现有记录和跳转能力，统一为手机列表和筛选面板 |
| 设置 | 全页分组列表，进入二级设置 | 将桌面式横向栏目改为分组列表和二级页面 |
| 阅读 | 默认隐藏操作，轻点正文呼出工具 | 增加沉浸阅读状态；保留清晰的返回入口和系统返回行为 |
| 阅读底部工具 | 目录、笔记、书签、主题、设置，附进度条 | 常用操作集中在拇指可达区域，沿用已验证的进度保存逻辑 |
| 目录 | 带搜索、层级和当前章节标识的底部抽屉 | 将手机目录侧板改为底部抽屉，复用现有章节树及跳转入口 |
| 主题和排版 | 底部抽屉中的大尺寸选项、颜色预设及设置行 | 复用字体、字号、主题等配置，统一触控区域和面板外观 |

参考导航、信息层级、触控行为和视觉节奏；具体入口按本项目当前已经实现的功能组织。字体、颜色、圆角和间距在手机组件中统一定义，继续响应已有主题配置。

## 分批顺序

1. **手机主界面**：底部导航、首页/书库、继续阅读卡片和导入/搜索入口。先完成可在真机操作的主界面，检查浏览、找书和恢复阅读。
2. **阅读交互**：沉浸工具栏、底部阅读菜单、目录/书签/笔记抽屉，再接入主题和排版。验证手势、返回、选区、键盘及阅读位置。
3. **设置与细节**：全页分组设置、二级页面、全局笔记和书架的布局，以及空状态、长标题、深色主题和安全区域。

每批均保留本地导入到退出后恢复进度的完整流程，完成一次真机回归后再扩展下一批。后续基础功能开发与新 UI 逐步衔接。

## 第一批：手机主界面

- 首页、书架、笔记、设置四个底部入口；首页保留收藏、最近添加、最近阅读和回收站分类。手机使用三列封面网格，沿用共享书籍列表的筛选、元数据加载和滚动加载。
- 首页继续阅读卡片显示最近实际打开的书及保存进度，直接调用既有打开书籍和进度恢复逻辑；只导入而没有阅读的书不显示为继续阅读。
- 顶部导入和可展开的搜索框，继续使用已有系统选书器及搜索逻辑。中文组词事件不再修改手机书库之外的阅读锁配置；通知移至底部，避免遮挡顶部操作。
- 独立书架列表、新建书架、进入书架、返回书架列表及管理入口。书籍菜单的加入书架操作在 Android 内即时跳转，继续使用原生配置持久化。
- 手机系统返回优先关闭搜索、新建书架表单、书籍菜单和书架管理弹窗；书架内先返回列表，再回首页。笔记与高亮沿用现有记录页面，设置沿用现有弹窗，二者的完整布局重构留在第三批。
- Android 主界面有独立颜色变量、深色主题、空状态及触控尺寸；新增文本提供英文和简体中文，其他语言沿用现有英文回退。

浏览器用例为 `e2e/android/library.spec.ts`，原有离线、阅读、批注和字体用例同步更新入口。真机在已有合成测试书上先运行 `yarn test:android:device`，再运行 `yarn test:android:library`；后者实际触屏操作导航、搜索、书架和继续阅读，创建的空测试书架在验收后删除，不清除应用数据。

## 第二批：阅读工具与底部抽屉

- 默认隐藏阅读工具。轻点正文或点击右下角菜单入口显示顶部返回、当前书名、添加书签及收起按钮，底部显示进度、前后翻页和目录、笔记、书签、主题、设置入口。
- 沿用 Viewer 已有的 iframe 点击和指针监听；短按才切换工具，长按、拖动、多指及链接/输入控件操作不触发菜单。笔记/选字菜单出现时收起阅读工具，避免遮挡引用、编辑与保存操作。
- 目录、书签、笔记和高亮使用原有 NavigationPanel 的数据、搜索、层级、筛选及跳转实现；Android 容器改为底部抽屉和触控切换按钮。章节或记录跳转后自动关闭抽屉。
- 主题和排版沿用原有 SettingPanel，使用独立主题/字体入口打开底部抽屉；原有布局、字体、主题及更多设置标签仍可切换。
- 紧凑进度条复用 ProgressPanel 的进度记录和跳转；触屏松手后跳转，前后翻页与桌面使用同一个处理函数。添加书签复用 OperationPanel，阅读实例重建时解绑旧监听并等待新实例。
- 保持上一批已验证的正文边距，工具栏和抽屉覆盖显示；显隐不重建正文、不改变阅读视口。保留既有旋转、键盘延后重排和退出持久化逻辑。
- 系统返回优先关闭抽屉，再收起工具，最后退出并保存。关闭按钮和遮罩也可关闭抽屉。

新增 `e2e/android/reader-ui.spec.ts` 验证实际轻点时的视口、正文节点及进度稳定性，检查五个抽屉入口和触屏进度跳转恢复。原有回归更新为先呼出阅读工具；真机阅读脚本增加物理轻点、返回及进度条持久化验证。设置页面的全页分组布局仍留在第三批。

- APK 离线编译并覆盖安装至 SM-S9110。原有冒烟 12 项、新版阅读 12 项、字号和批注 5 项真机检查全部通过。

## 第三批：分组设置与全局笔记

- 手机设置使用阅读与外观、书库与文本、工具与应用三个分组，进入独立二级页面；底部主导航保持可用。保留 General、Reading、Appearance、字体、TXT 解析、文本规则、插件、AI、更多及关于等已有内容，桌面继续使用原来的侧栏布局。
- 手机总览按当前已接入的能力组织，尚待原生适配的背景图片、数据导出/备份等未加入总览。原有对应组件继续保留，未扩大本批底层功能范围。
- SettingDialog 的页面内容通过同一个映射供桌面和手机使用。手机二级页、设置首页和字体预览分层返回；从阅读器直接进入设置时，返回到阅读界面。桌面专用的重置主窗口位置入口不再出现在手机通用设置中。
- 全局笔记和高亮改为单列触控卡片，显示日期、笔记、引用、标签、书籍和章节，提供明确的编辑与书中定位按钮。
- 书籍和多个标签采用交集筛选，并与当前搜索结果结合；筛选后提供计数、已选条件和重置操作。筛选抽屉先处理返回，再轮到搜索框，避免关闭抽屉时丢掉查询。
- 复用已有批注编辑和持久化。手机全局编辑器增加关闭入口，布局限制在当前键盘视口内；系统返回先收起键盘，再关闭编辑器，未保存草稿不覆盖记录。
- 共享 CardList 保留分页读取，改用公共 throttle 处理滚动。每次筛选重置分页批量，不再逐次增大；异步请求通过版本检查丢弃上一次筛选或已卸载页面的结果。
- 书籍、设置、批注继续通过现有 Zustand、DatabaseService 和原生桥接读写，没有增加状态命名空间、依赖或直接 SQLite 操作。

新增 `e2e/android/settings-notes.spec.ts` 覆盖十个设置页、字体预览返回、搜索与筛选、编辑定位、多页加载、快速切换和窄屏深色空状态。`scripts/android-settings-notes-device.cjs` 使用已有合成测试书，创建三条临时记录及一份临时字体，验证原生返回和键盘编辑后清理，并核对原有记录及书籍仍然完整。

## 实施时需要保留的行为

第三批之后已将字体、批注和三批手机 UI 集中提交并推送至 `codex/android-phone-prototype`，检查点为 `3b6ae0cc`。随后接入背景图片原生存储，阅读分组新增“背景”入口，支持本地导入、应用/阅读背景、预览分层返回及触屏删除。预览适配窄屏、横屏和深色模式；背景资源迁移和真机验收见 `ANDROID_PROTOTYPE.md`。该后续批次尚未提交。

背景之后，书库分组新增“数据”页，提供已接入系统另存为的原书、笔记、高亮及查词记录导出；导出期间显示忙碌状态并禁止重复操作，空数据和系统取消各自处理。全量备份/恢复等入口仍待原生能力就绪后接入。

随后在安卓“数据”页加入完整备份/恢复。恢复先校验并展示日期、图书/批注/文件数量，再由用户确认替换；预览和操作期间限制底部导航与设置页返回，系统返回优先关闭预览。真实书库用于创建与读取校验，覆盖恢复在独立 QA 应用中完成；技术实现和验收记录见 `ANDROID_PROTOTYPE.md` 的完整备份章节。

- Zustand 继续作为唯一状态源，保留既有八个命名空间；组件按字段订阅。
- 使用 Android 专用组件组织手机界面，保持桌面现有组件的布局。
- 阅读工具栏和底部抽屉采用覆盖方式显示，显隐时尽量保持正文视口尺寸，减少重排和阅读位置变化。
- 复用既有退出保存、原生返回、目录/笔记跳转及键盘期间延后重排的实现。
- 底部抽屉支持点击遮罩关闭；系统返回优先关闭当前面板，然后退出阅读或返回上级页面。
- 保留当前导入、离线读取、批注、字体及进程恢复回归，并将测试定位更新至新界面。
