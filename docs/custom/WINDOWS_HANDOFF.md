## 验证与限制

- 本地 TypeScript 检查通过；Vitest 10 个文件 / 75 项测试通过；108 个英文、简中 custom 文案键一致。
- 本机多角色：350 条文本 / 44 批对齐，MiMo 播放推进至第 4 条后停止测试。
- 本机生词：100 段 / 13 批对齐，阅读界面出现 195 处非空释义，无格式错误。
- 用户当前 Gemini 兼容地址的角色分析、翻译、生词均以短合成文本实测成功；原生与兼容模型列表、原生短 JSON 调用成功。完整原生阅读调用遭遇服务方 503 繁忙，没有取得原生三项全通过的结论。
- 上述本机验证通过临时内存适配执行，没有替换安装文件。测试后已清理适配与模型覆盖值，软件无调试参数正常重开。
- 本轮没有本地生产构建、安装 Windows 编译组件或打包；最新提交的 Windows 构建与隔离冒烟仍以 Actions 记录为准。
