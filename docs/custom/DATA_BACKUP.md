# 跨平台阅读数据备份

本约定取代安卓早期的完整书库 ZIP。原书通过系统文件映射读取，备份只保存阅读数据；不把电子书、封面、字体或背景文件装入备份。

## 共享格式

`src/custom/backup/dataBackup.ts` 是 Windows 与 Android 共用的纯数据编解码和恢复规划实现。JSON 的 `format` 为 `koodo-reader-custom-data-backup`、`version` 为 `1`，包括创建时间、`document`、阅读偏好白名单和 SHA-256 校验和。

`document` 直接使用已有 Windows 自有同步协议 `koodo-reader-custom` v1：完整原书 SHA-256 为书籍身份，笔记/书签使用持久 UUID。沿用 `sync/data.ts` 和 `sync/contract.ts`，覆盖书目元数据、进度、笔记、高亮、书签、书架、收藏、回收站标记、最近阅读、标签、时长和每日统计。导出不包含本机书籍 key、书籍路径、content URI、封面数据或同步凭证。进度内的章节相对链接是阅读位置的一部分。

阅读偏好单独使用明确白名单，不修改云同步 Envelope 的 kind 集合。字号、字体名称、行距、段距、颜色、阅读样式等可携带；系统权限、设备路径、窗口行为、服务连接和 API 密钥保留在本机。自定义字体、背景的文件内容需在各端另行添加。本文件是备份快照，不执行自动云同步或冲突合并。

## 恢复语义

只对本机已存在且完整内容指纹相同的书应用备份数据，保留本机 key、路径、content URI、封面和原书。不会创建空壳书目或替换整个书库。不同设备上的同名文件不等同于同一本书；原书缺失/不可读时不会使用过期指纹静默导出。

缺书的数据保留在本机数据检查点中，并提示先关联相同原书、再恢复该备份。后续导出仍携带未匹配的数据。重复恢复按稳定 UUID 更新笔记/书签；对于独立导入但内容相同的笔记，先按共享字段匹配，避免重复。还未建立共享身份的、内容不同的本地笔记会保留。

## 平台适配

- Android：`ACTION_OPEN_DOCUMENT` + 持久读权限，只在本机 SQLite 元数据中保存 URI 映射；读取由 ContentResolver 完成，不向私有 `book/` 写入新导入原书。删除书目只解除映射，不删除外部原文件。旧版已存入私有目录的书保持可读，不擅自清除。
- Android 恢复：通过 `database-command` 的库快照锁完成，写前记录仅含数据的回滚日志。失败或启动发现未完成事务时恢复表与偏好，不复制、交换或替换原书目录。偏好版本随回滚前进，避免后续正常保存被判为过期。
- Windows：自有同步设置增加数据备份导入/导出，可在未配置云服务时使用。沿用关闭阅读窗口检查、会话锁、`customSyncBatch` 比较后写入和本地回滚备份，不直接从渲染进程读写 SQLite。Windows 既有本机自动快照/同步回滚备份保持原用途，不等同于此可移植 JSON。

Windows 接入代码与共享实现目前位于安卓开发分支，需按共享改动合回桌面分支后发布。桌面当前已安装版本不因此自动更新；旧安卓完整 ZIP 也不能作为新的阅读数据 JSON 直接导入。

## 验证

单元测试覆盖两端不同本机 key/路径、进度/批注/统计恢复、偏好与密钥隔离、重复恢复、缺书保留、指纹缺失及损坏文件。Windows 适配器使用独立配置目录测试离线完整流程。安卓原生测试覆盖书目集合/路径保护、部分写入失败、重启回滚及原书不变。

真机脚本 `yarn test:android:backup --primary` 只导出并核对主库；`yarn test:android:backup` 在全新 `.restoreqa` 包中进行真实书籍映射及恢复，禁止主库恢复测试。报告、截图和备份数据留在忽略跟踪的 `dist/android-device/`。执行后卸载 QA 包，并删除脚本创建的临时原书。浏览器测试端口可通过 `ANDROID_TEST_PORT` 覆盖。

2026-11-03 验收：类型检查、151 项单元测试、24 项手机浏览器回归、24 项安卓原生测试通过。真机主库保留 8 本书、11 条笔记/高亮，导出的 JSON 为 23,540 字节。隔离实例确认真实 EPUB 无私有原书副本、不同本机 key/URI 下恢复进度、重复恢复不新增记录、重启后仍可阅读翻页。最终主应用已覆盖安装；QA 包及 5 个经内容指纹核验的临时原书已清理。阅读器内备份按钮禁用，服务层也要求先关闭阅读器。
