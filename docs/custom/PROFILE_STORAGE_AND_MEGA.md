# 配置目录随书库迁移与 MEGA 会话修复

## 存储布局

外部书库的配置、Chromium 存储、MEGA 会话、代理、缓存、日志和崩溃目录统一放入 `<书库存储位置>/app-profile`。书籍、封面和数据库仍位于原书库根目录的 `book`、`cover`、`config` 等子目录；`snapshot` 和 `sync-backups` 保持原用途。

`%APPDATA%/koodo-reader-custom/profile-location.json` 只记录实际 profile 和书库位置，不存账户和 API 凭证。程序在此稳定位置取得单实例锁，再读取指针，在加载 electron-store、Chromium session 或数据库前设置实际 profile。首次使用新版本时，已经选择外部书库的用户会自动迁移原 profile。仍使用内置默认书库的用户在选择外部位置时迁移。

“更改存储位置”要求选择独立空目录，准备迁移后重启。退出释放数据库与 Chromium 文件，下一次启动在目标同一磁盘的临时目录复制书库及配置，逐文件核对 SHA-256，再发布目标目录、提交启动指针并清理原文件。未完成校验前保留原数据；复制失败可重新启动使用原位置。目标磁盘不可用时停止启动，不能自动回退到 C 盘空配置。被占用而无法清理的原文件保留。

迁移保留同步的 deviceId、因果时钟、备份及恢复标记，只修改因本机书库路径变化而变化的检查点索引。如果本地同步目录也位于被迁移书库内，它随书库一起迁移并更新连接路径；书库外的同步目录保持原位置。

“切换书库”保留原书库。已有 `app-profile` 的目标使用自己的设置；尚无 profile 的目标接收当前配置，并按原有切换逻辑载入所选书库的 `config/config.json`。原默认书库即使位于旧 profile 内也保留。清空数据保留正在使用的 profile 目录和存储路径，清除业务数据、账户及偏好，避免删除 Chromium 正在使用的文件。

不要单独删除 AppData 的启动指针；否则程序无法知道外部 profile 在哪里。备份整个指定书库目录包含 `app-profile`，即可同时保存书库与应用配置；MEGA 等系统加密凭证仍受 Windows 用户/机器的加密边界约束，不能保证在另一台电脑直接解密。

## MEGA 会话

本地 SDK `megajs` 的 `Storage.close()` 调用 `sml` 注销服务器会话。旧实现保存会话后用此方法清理登录/读写连接，导致下一次恢复被 MEGA 拒绝。现在只调用 `storage.api.close()` 停止本地轮询，不注销保存的会话。

旧代码已经注销的会话无法恢复；升级后需要在 MEGA 设置中填写密码，重新登录并保存一次。不会要求将密码交给开发者，也不会持久化原密码或验证码。

## 2026-11-04 启动指针复用

Windows 重启核对复现 `profile-location.json` 的替换式重命名返回 `EXDEV`。原启动流程在没有迁移、路径没有变化时仍重写同一个指针，因而停止启动并显示通用存储迁移失败提示。该提示不能单独证明权限不足，提高启动权限也没有解决此次错误。

现在仅在版本、profile 或书库路径变化，或有待提交的迁移时提交指针。已建立的连接直接读取指针并设置运行目录；不改为覆盖式非原子写入，实际迁移和切换仍经过原有复制校验、原子提交与失败恢复流程。

新增回归先复现 `EXDEV` 导致正常重开失败，再验证已有 profile 和指针字节保持不变。11 项 profile 回归、全量 141 项测试及类型检查通过；现有用户配置的启动检查也通过，指针内容与设置文件保持不变，见忽略跟踪的 `dist/windows-mega/profile-check.json`。该检查没有访问数据库或上传云端数据。

启动补丁已安装到当前 Windows 应用，仅替换 `src/utils/main/custom/profile.js`，保留此前已验收的 MEGA 修复及归档其他成员。原始安装版备份仍在 `dist/windows-mega/backup/app.asar`；仅包含 MEGA 修复的中间版本备份在 `profile-backup/app.asar`。最终归档 SHA-256 为 `2a5783aa10a0454622b420f93a9453a046b5d3f3150c50d28ce5b737ce2f4d4c`，与候选一致。启动失败的提示正常确认后退出，更新后重新打开应用，主窗口可见且响应正常，见 `profile-installed-report.json`。未修改书库位置或目录权限；本次安装经 Windows 管理员确认，普通权限启动未另行验收。

## 验证边界

单元回归使用隔离临时目录和合成数据，覆盖原配置迁移、完整书库迁移、默认嵌套书库、切换已有书库、指针提交中断、复制失败、目录冲突、磁盘不可用、同步身份/备份重定位及实际 MEGA SDK 多次复用同一合成会话且不发送 `sml`。未连接用户的真实 MEGA 账户。
