# 安卓 MEGA 阅读数据同步

手机设置 → 自有云同步（Personal sync）使用与 Windows 相同的 MEGA 账号和同步空间。按所有者最新要求，安卓只保留手动同步：首页顶部“云同步”，或设置中的“立即同步”。没有配置账号时，首页按钮打开连接设置；有冲突时进入版本选择。既有自动调度已停用，设置不再提供自动间隔；桌面设置不受此改动影响。

## 数据与兼容

沿用 `koodo-reader-custom` v1 信封及 `KoodoReaderCustom-v1-<namespace>` 目录，不增加旧客户端不认识的字段或 kind。共享完整原书 SHA-256、批注 UUID、因果时钟、冲突选择及计数器语义。覆盖进度、笔记、高亮、书签、书架、收藏、回收站标记、最近阅读、标签、累计时长和每日统计，不传原书、封面或本机路径/URI。

`sync/workflow.ts` 供两端复用合并规划、书籍映射和批注身份。手动备份与同步复用本机批注标识；首次接入已有云空间时，对已复制且共享字段完全一致的批注进行一对一身份关联，避免“先导入备份，再同步”产生重复。保留本机书籍 key、文件映射和格式。缺书的远端数据留在检查点，关联原书后再同步应用。

阅读偏好仍通过上一批的阅读数据 JSON 备份交换；v1 云协议暂不自动同步设置，避免破坏已安装的 Windows 客户端。文件夹通道仍仅在桌面端提供。

## 本机存储和生命周期

- MEGA 会话存放在 `getNoBackupFilesDir()` 的加密文件，使用 Android Keystore 生成的 AES-GCM 密钥及随机 IV。登录后删除待保存会话中的密码、二次验证码和 fetch 函数；登录表单不写入 localStorage。
- 账号/空间各有独立设备检查点。Android 系统备份与设备传输规则排除应用私有数据，防止复制原书、凭证或设备时钟；用户迁移使用可移植阅读数据 JSON，并重新登录/关联原书。
- 沿用桌面 MEGA 目录重建、缓存变更追赶、不可变快照、字节校验及本设备三代清理。两端共用 `utils/main/custom/megaTransport.mjs`，Electron 打包清单包含该 ESM 文件。
- 网络阶段不冻结书库。原生快照锁仅用于捕获/暂存和最终应用；上传前持久化待发修订，上传失败后可重试。最终应用检查本地数据及连接空间是否变化。
- 暂停偏好观察期间若出现本机编辑，应用中止并重新排队保存该编辑。若编辑或进入阅读器发生在原生提交响应期间，锁内回退本次应用，保留新操作。原生数据写入继续使用上一批的回滚日志，不复制书籍目录。
- 仅在明确点击时运行同步。关闭 SDK API 停止本机轮询，不调用会注销持久会话的远端 logout。

## 手机两本、电脑全库时如何合并

- 依据原书完整内容 SHA-256 识别同一本书，不依赖设备路径或文件名。名字相同但内容不同的版本不会强行合并。
- 手机只导入两本时，只向本地应用这两本的进度、笔记、高亮、书签、书架关系、收藏、回收站标记、最近阅读和时长；未导入的书及相关数据保留在云端和同步检查点。未下载不等于删除。标签和书架名称可以共享，手机仅展示本地书的关联项。
- 当前手机统计页汇总本机已关联的书，电脑全库统计覆盖电脑已有书。因此两端显示的总量可能不同，但同一本书的时长和每日记录会合并。以后导入同一原文件，再同步即可应用之前保留的数据，不创建空书目或下载原书。
- 不同笔记/书签各自保留；相同稳定身份不会重复新增。同一条笔记或阅读位置被离线分别修改时，保留两个版本并提示选择；选择前临时显示一个确定的版本，不按手机时钟或“阅读更远”擅自决定。并发删除与修改暂按删除显示，仍保留另一版本供选择恢复。
- 累计时长和每日时长按“共同历史 + 各设备新增”合并，例如共同 100 分钟，手机新增 10、电脑新增 20，结果 130，重复同步仍是 130。首次接入已有的旧总量按较大值建立共同起点，避免把复制来的历史再次相加；不会直接相加两端显示的总时长。
- 网络中断后复用待发修订重试，不重复计时；应用数据前检查本机是否又发生编辑，发生变化则保留本机新操作，等待下次同步。手动同步需要每端主动收取变化，例如电脑同步 → 手机同步 → 电脑再同步，最后一轮才能收齐手机的新改动。

本轮修复了新设备首次接入时把已有云端增量重复累计的问题，并对 MEGA 已不存在节点的重复删除通知做兼容；SDK 重载产生的重复变更监听只执行一次。均先用合成数据复现，再修复并回归。真实账号验证只写独立测试空间，真实同步空间前后内容一致且未写入样本，见 `dist/android-device/mega-live-report.json`。

## 验证方式

`yarn test:android:sync` 仅在独立包 `xyz.koodoreader.custom.android.restoreqa` 中写入合成账号和数据。复用 `e2e/android/mega-fixtures.cjs`，实际运行已安装 MEGAJS SDK 的加密上传/下载，Playwright 将全部 MEGA 请求转入内存服务，不访问真实账户。Node 桌面传输实现与手机 WebView 使用相同测试服务验证双向兼容。

覆盖已有批注的备份身份关联、跨本机 key 的进度/书签恢复、手机改动回传桌面、失败上传重试、统计不重复累计、重启读取加密会话及检查点、不变数据不新增云代次、主书库不变。原生仪器测试覆盖加密后重开、随机 IV、损坏密文拒绝与凭证删除。2026-11-04 已使用手机现有登录会话完成真实公网验证，写操作限于独立测试空间；没有修改真实同步空间，也未刻意耗尽配额或覆盖其他代理环境。
