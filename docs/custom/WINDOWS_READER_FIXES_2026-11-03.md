# Windows 阅读交互修复（2026-11-03）

本次修改位于 `custom/dev`，不包含 Android 分支功能。未构建安装包或修改现有安装文件。

## 行为与原因

1. **朗读中无法选字**：实际阅读引擎更新朗读高亮时会重建文本节点并清空原生选区。现在在拖选、已有选区或笔记菜单打开时保护选区，跳过破坏选区的自动高亮；到翻页边界时等待选字操作结束。复用现有文档事件绑定，不新增高频鼠标移动监听。
2. **标签首次点击没有反馈**：新笔记的标签组件一直收到空数组，父组件重渲染后又重置选中项。现在传入当前编辑中的标签，新增和编辑笔记均即时显示选中状态，保存值与界面一致。
3. **朗读弹窗重开状态错误**：隐藏弹窗曾卸载播放器组件，自有音频仍可能继续播放，而新组件认为尚未开始。现在同一本书的播放器实例保持挂载，点击朗读按钮开关面板，点击正文或关闭按钮隐藏；退出阅读或更换书籍时才停止和清理播放器。上一句、下一句和停止按钮使用真实禁用状态。
4. **暂停与继续**：主播放按钮增加文字提示和可访问名称。暂停会覆盖语音生成、音频加载和实际播放阶段；后台缓存完成不会取消暂停，快速暂停后立即继续会复用尚未结束的加载。停止时丢弃过期加载，切换音色和跳句后的旧播放循环按会话校验。自有音频继续时保留当前播放位置。
5. **E-ink**：界面及正文白底黑字，封面和插图灰阶，边框清晰，关闭阴影、装饰背景和翻页动效。保留弹窗关闭所需的动画结束回调。退出 E-ink 时恢复原配色与翻页设置，不改写原偏好。

## 重复运行 Windows 隔离检查

先启动干净的开发服务：

```powershell
yarn start
```

在另一终端将已安装的 Custom 程序路径传给测试脚本：

```powershell
node scripts/custom-reader-smoke.cjs "D:\Program Files (x86)\Tools\Koodo Reader Custom-2.4.7-x64-Win\Koodo Reader Custom.exe"
```

脚本检查 profile 隔离，阻断外部 HTTP 请求，通过应用 IPC 写入合成书籍和笔记，结束后关闭测试进程并移除自己的临时 profile。截图与检查摘要写入 `dist/reader-eink.png`、`dist/custom-reader-smoke.json`。仅使用支持 `KRC_TEST_PROFILE` 的 Custom 程序；该脚本不会替换安装文件。
