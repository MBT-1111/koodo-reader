# Android AI 与翻译

2026-11-03，优先适配用户选择的 Gemini，分支 `codex/android-phone-prototype`。

## 使用入口

1. 在“设置 → AI 服务”添加模型，选择 Gemini 服务商，填写 API Key 和实际使用的接口地址。可获取模型列表，也可手动填写模型 ID；支持原生 Gemini 地址及其 OpenAI 兼容地址。连接测试通过后添加，再分别选择“AI 翻译模型”和“AI 词典模型”。
2. 阅读 EPUB、TXT 等可重排书籍时，打开阅读工具，点击“翻译”。可选择当前页双语显示、仅译文、目标语言，以及词义注释。原始 PDF 暂不提供这一入口。
3. 选中文字后点击翻译，选择自定义 AI 翻译服务。该入口也使用已分配的翻译模型。

“当前页翻译”只发送视口中的完整段落，不会一次发送整本书；词义注释沿用既有章节批处理。关闭翻译后恢复原文。返回键关闭底部翻译面板，配置不足时进入 AI 设置。

## 请求与兼容

原生 Android 使用已安装的 Capacitor HTTP 能力发送 AI、翻译和查词接口请求，不受 WebView 跨域策略限制；没有全局关闭 WebView 网络限制。模型列表、连接测试、选字翻译、页内翻译和词义注释复用同一请求适配。

Gemini 使用原生 `generateContent`、请求头中的 `x-goog-api-key` 和既有响应解析；OpenAI 兼容接口继续使用原有协议。手机选字 AI 请求先等待完整响应，再显示结果，本批没有实现原生逐 token 流式输出。普通浏览器和 Electron 的通用网络行为保持原有路径；Gemini 选字调用补齐了原生协议。

配置可在获取列表前编辑，模型列表获取失败时仍可手动添加。连接测试与模型列表按钮在请求中禁用，失败后可再次操作。修复一次性返回结果时，翻译缓存被清空导致界面显示空白的问题；错误会结束等待状态。

原生调用拒绝非 HTTP(S) 和带用户名/密码的 URL，禁用自动重定向，不在应用日志中输出密钥或书籍文本。使用 HTTPS 服务；仅 debug 构建允许 `localhost`、`127.0.0.1` 的明文请求，用于 ADB 转发的隔离测试。翻页取消会忽略过期结果；底层 Capacitor HTTP 暂不能中断已发送的请求，服务端仍可能完成计算。

## 验证

单元测试覆盖原生/浏览器分支、请求头鉴权、JSON 响应、取消后的延迟结果、URL 校验，以及现有翻译插件的查询参数、JSON 变换和 HTTP 错误。

`e2e/android/ai.spec.ts` 覆盖 Gemini 添加、模型列表、鉴权失败重试、重载保留、底部翻译面板、双语渲染/关闭和选字结果。接口由隔离测试服务提供，不使用真实密钥。

本轮类型检查、25 个文件 / 174 项 Vitest、完整 32 项手机界面回归、Android lint 与 APK 编译通过。SM-S9110 / Android 16 的 7 项实机检查通过，覆盖原生 HTTP、鉴权失败重试、重启配置、双语翻译、中文词义注释、选字翻译和数据恢复；主库 8 本书、11 条笔记、1 个书签及空查词/插件表的内容哈希不变。

最终 APK 已再次覆盖安装，入口资源与本地最终构建匹配；升级前数据摘要、临时模型清理及原 E-ink 偏好复核通过，见 `dist/android-device/ai-final-report.json`。

```powershell
$env:ADB_PATH = '现有 Android SDK 的 platform-tools/adb.exe'
yarn test:android:ai
```

真机脚本通过 ADB 转发到本机 Gemini 协议测试服务，服务不返回 CORS 许可头，从而实际验证原生请求。使用既有合成《安卓章节样本》，不访问真实 Gemini 账户。测试完成后删除临时模型配置，恢复原来的模型分配、阅读位置、统计与最近阅读，并核对主库各表不变。结果位于忽略跟踪的 `dist/android-device/ai-report.json` 和 `ai-*.png`。

真实 Gemini API Key、账号配额、模型权限和公网网络仍需在应用内配置后验证。云 TTS、原生流式输出、跨进程翻译缓存和专用扫描 PDF 翻译不属于本批。
