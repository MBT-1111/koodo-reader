# Android E-ink 显示模式

2026-11-03，分支 `codex/android-phone-prototype`。

## 使用

在“设置 → 外观 → E-ink 模式”开启。书库、书架、笔记、设置和阅读工具使用白底黑字、黑色边框，关闭阴影、过渡和动画。封面、插图和 PDF 保留灰阶细节。EPUB/TXT 正文强制白底黑字，批注通过黑色下划线保持可见；翻页动画实际使用“无”，进度滑块和书签标记使用黑白显示。

开启时隐藏应用背景和书籍背景图。原来的应用主题、主题色、正文颜色、背景图片与翻页动画设置均保留；关闭后恢复。阅读器的配色页显示模式说明，动画选项显示“无”并禁用，避免界面选项与实际显示不符。背景管理页仍可管理图片，并说明图片暂时隐藏。模式通过现有原生配置存储保存，杀进程后仍然生效。

正文样式只在 Android 生效，桌面沿用原有 E-ink 行为。复用原有开关、主题初始化、渲染选项和翻页节流，没有新增刷新定时器、触控监听或配置副本。

## 验证

新增 `e2e/android/eink.spec.ts`，覆盖真实开关、深色主题下的黑白显示、导入按钮和翻页箭头对比度、背景隐藏及恢复、正文颜色、动画选项、页面重载，以及窄屏/横屏的 TXT、PDF 和抽屉操作。单元测试补充 Android 正文覆盖与桌面兼容检查。

类型检查、24 个文件 / 168 项 Vitest、完整 30 项手机浏览器回归及 Android lint 通过。最后的对比度样式调整后，E-ink 与阅读工具的 4 项浏览器用例再次通过；最终 APK 已重新构建并覆盖安装，11 项实机检查通过，包含真实键盘下的笔记编辑器和原生返回。

实机脚本：

```powershell
yarn test:android:eink
```

需要一台已解锁、授权 ADB 的手机，以及已导入的合成样本“安卓章节样本”“安卓文本样本”“安卓 PDF 样本”和 EPUB 批注。脚本使用现有书籍，检查实际触控翻页、批注标记、原生配置持久化、进程重启和关闭后的配色恢复；结束时恢复原来的外观、阅读位置、统计及最近阅读，并核对主数据库内容。报告与实体屏幕截图位于忽略跟踪的 `dist/android-device/eink-report.json` 和 `eink-*.png`。

本次在 SM-S9110 / Android 16 完成覆盖安装和显示、触控回归，保留原有 8 本书、11 条笔记和 1 个书签。该手机使用普通显示屏；专用墨水屏硬件的刷新驱动、残影和功耗仍需在对应设备上验证，本实现不调用厂商刷新接口。
