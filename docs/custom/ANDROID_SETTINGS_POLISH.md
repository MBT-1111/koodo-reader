# Android 插件设置整理与选句朗读

2026-11-03，分支 `codex/android-phone-prototype`。按用户要求先整理手机“设置 → 插件”，移除手机设置中的 About，再继续补齐“从这里朗读”。

## 插件页

- 翻译、词典、语音、OCR 分类同时筛选已安装插件与插件市场，手机不再把所有分类堆在一张长列表中；书内朗读面板跳转时仍可直接打开语音分类。
- 名称/图标与操作分行显示，长名称和详情按手机宽度换行；详情、安装、删除及底部入口保留至少 44px 的点击高度。
- “访问在线版本”“如何自定义插件”“添加自定义插件”放回正常文档流，纵向排列并随内容滚动，避免绝对定位覆盖插件列表。添加自定义插件的现有确认、验证及平台限制继续生效。
- 320px 窄屏的分类按钮分为两列；普通手机、横屏、深色与 E-ink 配色沿用设置页变量。样式由插件组件显式导入，桌面的列表/分类滚动行为保留。
- 手机设置不再显示 About；旧的手机 About 状态回到设置分组。桌面 About 保留。

## 从这里朗读

手机选字菜单的“从这里朗读”复用现有起点与自动启动状态，等待当前书籍和音色就绪后仅消费一次启动意图。正文从选中的句子起保留本章后续文字，再应用听书文本规则；系统、Azure/MiMo 与多角色分析使用同一个入口。

选中文字不在本章可定位范围时显示提示，不静默从其他位置朗读。已有会话会先停止；正在角色分析时的新选句取消旧分析。关闭再打开朗读面板不会重复启动。停止或退出阅读清除选句意图，避免下本书继承旧起点；新意图到来时旧请求不会清除新起点。

本批仍不包含自动跨章、跟读翻页或朗读位置跨进程恢复。

## 验证入口

```powershell
yarn typecheck
yarn test --maxWorkers=2
yarn build:android
yarn test:android
$env:ADB_PATH = '现有 Android SDK 的 platform-tools/adb.exe'
# 安装新 APK 前记录摘要，不保存明文配置或凭证
yarn test:android:plugins --baseline
# 安装新 APK 后检查手机布局及数据保全
yarn test:android:plugins
yarn test:android:speech
yarn test:android:cloud-speech
```

新增浏览器布局检查覆盖分类、安装/删除、长名称详情、三种视口、页脚按钮命中、中文 E-ink 和 About 移除；选句回归覆盖自动启动、准确起点、替换播放、关闭重开和停止后不重播。真机插件页脚本只查看分类/详情和界面，不安装、删除或修改已有插件，核对升级前后的主库与完整偏好哈希。

设备报告与图片位于忽略跟踪的 `dist/android-device/plugin-settings-report.json`、`plugins-phone-voice.png` 和 `plugins-phone-footer.png`。

本批类型检查、183 项 Vitest、完整 37 项手机界面回归及 Android APK 编译通过。最终 APK 已覆盖安装；SM-S9110 / Android 16 的插件页四项检查通过，页脚三按钮在实际 WebView 内独立可点，主库五张表与安装前一致。用户确认安装期间自行调整了设置/阅读，因此偏好按每次界面检查开始时的当前状态比对，安装前摘要是否一致另行记录；保留此前主库基线，没有回滚用户配置。界面操作前后完整偏好哈希一致，不将整个使用/朗读测试期间的偏好摘要变化报告为完全一致。
